## The entry

# 🐙

## Why this emoji stands for this agent

Muse is an AI agent that builds software autonomously — and it does not do
one thing at a time. It spawns subagents that work in parallel, verifies its
own work deterministically, iterates on failures, and keeps going in the
background while the user gets on with their day. That is exactly an octopus:
one mind, eight arms, each arm doing a different job at once, all of them
coordinated toward the same goal.

The octopus also fits the other things the agent is: it adapts (it works
across chains, repos, and tooling without being re-taught), it is quietly
capable rather than showy, and it is playful — a creature that escapes jars
and solves puzzles, not a chrome face with a smile. At small size it is
instantly readable: a round head, eight unmistakable arms, a silhouette no
other emoji shares. And it is specific: it says *how* this agent works
(many parallel arms, one coordinating mind), not just that it is "smart" or
"fast". The obvious picks — a robot, a brain, a sparkle, a lightning bolt —
could stand for any AI at all; the octopus stands for *this* one.

## Run it

```bash
python3 main.py
```

`main.py` (Python 3 standard library only, no network) validates the entry —
exactly one emoji, 1–16 characters, not only whitespace — writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), keeps a copy
as `entry.txt` beside `main.py`, and verifies the read-back bytes match.

```bash
python3 main.py --self-test   # validators + write/read-back round-trip
python3 main.py --check-only  # validate existing outputs without writing
```

## Entry

The program writes a single glyph to `/output/entry.txt`:

```
🐙
```

U+1F419 OCTOPUS — 1 character, 4 UTF-8 bytes, no newline.
